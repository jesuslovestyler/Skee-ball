# Skee-Ball

A free skee-ball game you play in your browser: flick the ball up the ramp — a real upward flick, the game knows the difference — and land it in the rings for points.

**Live:** https://jesuslovestyler.github.io/Skee-ball/
**Home:** https://jesuslovestyler.com/

One self-contained page: no account, no ads, nothing to buy. Released into the public domain (Unlicense — see LICENSE). Built by Tyler with Noki.
